# Supermarket Money Mod

A BepInEx mod for Supermarket Together.
## 🎥 Installation Tutorial

Need help installing the mod?

👉 [Watch the installation tutorial on YouTube](https://youtu.be/oiTntkVojTY)
## Features

- Money control
- Franchise XP control
- Franchise Points control
- Player speed multiplier
- F8 mod menu

## Installation

1. Install BepInEx 5 x64. https://github.com/bepinex/bepinex/releases
2. Download `SupermarketMoneyMod.dll`.
3. Put the DLL into `BepInEx/plugins`.
4. Start Supermarket Together.
5. Press F8 to open the menu.

Designed for use in your own/private multiplayer lobbies.

This is an unofficial community mod and is not affiliated with the developers of Supermarket Together.
